# Midnight & Gold Foil • Luxury Ring Ceremony Invitation

A cinematic, quiet, expensive digital invitation for the Ring Ceremony of **Shailja & Vikas**, styled like high-fashion luxury stationery.

## Features
- **Cinematic Entry:** Gold rings draw in, monogram glows, and opens with an optical lens separation and warm flare.
- **Nine Editorial Chapters:** 100dvh full-screen sections with CSS scroll-snap proximity and IntersectionObserver fade-and-rise motion.
- **Midnight & Gold Foil Palette:** `--noir`, `--ink`, `--ivory`, `--bordeaux`, and multi-stop gold foil gradient.
- **Celebration 50/50 Split:** Tall mehrab arch window with solitaire ring and twinkling 4-point sparkle alongside refined typography.
- **Personalized Guest Links:** Safe injection via URL parameter `?to=Guest+Name` with dedicated `generate.html` VIP link generator.
- **Bilingual Support:** Real-time English & Hindi switcher (`EN / हिंदी`).
- **Interactive Actions:** WhatsApp RSVP, Add to Calendar (.ics), Web Share API with copy-link fallback, and Google Maps navigation.
- **Zero Build Step:** 100% vanilla HTML5, CSS3, and JavaScript — works instantly on GitHub Pages or double-clicking `index.html`.

## How to Customize in 3 Steps
1. Open `js/config.js` in any text editor.
2. Edit the couple names, date/time, venue address, WhatsApp phone number, and programme timings.
3. Save the file — the entire invitation automatically updates all chapters, countdown, translations, and calendar invite!

## Hosting Free on GitHub Pages
1. Push this repository to GitHub.
2. Navigate to **Settings > Pages**.
3. Under **Branch**, select `main` (or `master`) and folder `/ (root)`.
4. Click **Save**. Your live luxury invitation link will be ready in seconds!
